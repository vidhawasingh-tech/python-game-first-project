Python Car Dodging Game 🚗

A classic 2D arcade car dodging game built with **Python** and **Pygame**. Steer your car along the highway, dodge oncoming traffic, and beat your high score!

## 🎮 Features
* Smooth left and right lane steering
* Increasing difficulty and oncoming traffic obstacles
* Score counter and instant **Game Over / Restart** screen

## 🕹️ Controls
* **Left / Right Arrow Keys** (or **A / D**): Move the car left and right
* **R**: Restart the game after a crash

## ⚙️ How to Run Locally
1. Make sure **Python 3** is installed on your computer.
2. Install Pygame (or Pygame Community Edition):
   ```bash
   pip install pygame-ce
   ```
3. Run the game script:
   ```bash
   python myfirstprojectcaregame.py
   ```
